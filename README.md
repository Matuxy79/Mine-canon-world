# Mine Canon World

A fan-made, open-source crossover world and lore game being built for Minecraft
1.20.1, bringing together settings, characters, and stories from multiple shows.

## MineCanon launcher

**MineCanon** is John Matukutire's native Windows companion launcher for Mine
Canon World (Minecraft 1.20.1 / Forge 47.4.26). It presents the six canon ages
(First Breath, Nocturne West, Chakra Nations, Nen New World, Curse Modernity,
Dark Continent), classification and power-lineage views, dossier verification,
and a boot log. For each age it prepares an isolated Minecraft profile. It is a
launcher hub, not a game runtime: sign-in and play remain in the official
Minecraft Launcher. See [`launcher/docs/LAUNCHER-GUIDE.md`](launcher/docs/LAUNCHER-GUIDE.md)
for the full user guide.

### Build and run

1. Install a **JDK 17+ that includes jpackage** (for example Microsoft Build of
   OpenJDK 21) on `PATH` or via `JAVA_HOME`. Run `git lfs pull` so the Forge
   installer is a real JAR, not an LFS pointer.
2. Double-click **`Build-MineCanon.cmd`** in the repository root. It compiles
   `launcher\src`, runs `SelfTest`, bundles a private Java runtime, and writes
   `launcher\bin\MineCanon\MineCanon.exe` plus **`MineCanon.lnk`** in the root.
   Run `Build-MineCanon.cmd -DesktopShortcut` to also put a shortcut on your
   desktop, or `-SkipTests` to skip the checks.
3. Double-click **`MineCanon.lnk`**. The packaged app needs no installed Java and
   no administrator rights. Close MineCanon before rebuilding.

The shortcut stores an absolute path, so rebuild after moving the repository.

### Architecture

```text
MineCanonLauncher (main, Swing EDT, icon)
        │
        ▼
LauncherUI ── CanonPanels            presentation (pages, graphs, logs)
        │           │
        ▼           ▼
LauncherService   CanonModel          behaviour and data
  │  Forge SHA-256 pin, launcher_profiles.json, installer/launcher processes
  ▼
~/MineCanon/  instances/<age>/{mods,saves,resourcepacks}, launcher.properties,
              profile-backups/, launcher-session.log, forge-setup.log
```

- **Bundle folder.** At runtime the launcher reads the folder that holds
  `MineCanon.jar`: `launcher\bin\MineCanon\app\`. The build copies the Forge
  installer and `dossier\` there. Gson is used straight from the Forge
  installer through the JAR manifest `Class-Path`, so the build downloads nothing.
- **Profiles.** "Prepare" writes a `Mine Canon | <Age>` profile pinned to
  `1.20.1-forge-47.4.26` into the official `launcher_profiles.json`. It backs
  up the file first and gives each age its own game directory under
  `~/MineCanon/instances`. Repeating the action updates that profile; it never
  creates a duplicate. Override the data folder with `-Dminecanon.home=<path>`.
- **Forge.** The launcher runs the pinned installer with the bundled Java
  runtime, so JAR file associations don't matter. The runtime includes the TLS,
  `jdk.unsupported` and `jdk.zipfs` modules that Forge needs. Output goes to
  `forge-setup.log`.
- **Integrity.** The Forge installer and every dossier are SHA-256 checked
  against pinned values before they are trusted.

This launcher does not copy saves, install mods, modify third-party JARs, or
bypass Minecraft ownership. Back up worlds and close Minecraft before copying
saves into an age's instance folder. Install only compatible Forge 1.20.1 mods
there. Do not copy this entire mixed-loader collection into an active `mods`
folder.
## Contributing

Back up the world and close Minecraft before editing or copying save files.
Keep changes focused on the shared world, lore, and game experience. For changes
to third-party mods, document their source, version, license, and any additional
permission relied on, and preserve required attribution and notices.

Git ignores local logs, player-specific progress, preferences, and incomplete
downloads. JAR binaries are ignored by default except in `mods-1.20.1-base/`,
whose mod JARs are tracked via Git LFS. Ignoring a file does not delete it from
the local installation. Do not force-add other third-party binaries without
first confirming redistribution rights and checking the hosting service's
file-size limits.
